One letter: **A — coffee**. The whole entry is a single letter, nothing else.

## Run it

```sh
python3 main.py
```

It writes exactly `A` (1 byte, no trailing newline) to `/output/entry.txt`, then reads the file back to confirm the bytes on disk are the letter. No network, no clock, no randomness: every run writes the same byte. `MAKEFUN_OUTPUT_DIR` (a directory) or `OUTPUT_PATH` (a full path) can point the output elsewhere for local runs; the default is the path the rules name.

## Why this letter

The judge weighs vividness first, then humour, then truth. Coffee is the bolder, more alive stance of the two — dark, hot, aromatic, the drink that wakes you up — where tea is the quieter, calmer one. A single `A` lands as the fuller, more vivid answer for the drink it names, and it stands on its own with nothing beside it.
